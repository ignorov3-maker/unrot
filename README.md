# Unrot 🐹

**Превращаем брейнрот обратно в мозги.** Unrot скачивает сохранённые ролики из Instagram, расшифровывает их и превращает в личную базу знаний: конспекты, темы, вопросы к базе и портрет «Обо мне».

Этот репозиторий — канал обновлений: приложение само забирает отсюда новые версии.

- `latest.json` — описание последней версии (номер, что нового, контрольная сумма)
- `Unrot-<версия>.unrot-update` — файл обновления

Руками здесь ничего менять не нужно.
